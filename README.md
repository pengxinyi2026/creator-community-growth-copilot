# Creator Community Growth Copilot

An AI-assisted creator operations dashboard for community growth, creator segmentation, campaign matching, reactivation, and human-reviewed outreach workflows.

This project uses synthetic creator data and deterministic project-defined rules to demonstrate an end-to-end creator operations workflow.

## What this project does

The project turns creator-level performance data into an operational workflow:

```text
Creator Data
    ↓
Data Validation
    ↓
Creator Metrics
    ↓
Growth Scoring
    ↓
Creator Segmentation
    ↓
Campaign Matching
    ↓
Reactivation
    ↓
AI-assisted Insights & Outreach Drafts
    ↓
Weekly Operations Report
    ↓
Streamlit Dashboard
